Quel acces utiliser ?

Chaque role reste dans son espace. Le client consulte, l agent execute, la supervision coordonne et l administration pilote.

Client

Le meilleur parcours reste le lien direct genere depuis l administration. Il permet de definir le mot de passe puis d entrer dans le portail client sans configuration complexe.

Agent

L agent accede a son tableau de bord terrain, ses missions, ses clients affectes et les consignes synchronisees avec le centre OPS.

Admin

L administration gere les clients, les cameras, la carte, les comptes et les modules OPS depuis le dashboard central.

Superviseur, operateur, utilisateur

Les postes internes ouvrent uniquement les modules autorises par l administrateur: centre de controle, alertes, cameras, rapports, coordination terrain ou route.

Parcours client recommande

  • 1. Creer le dossier client dans l administration.
  • 2. Generer le lien portail direct avec token.
  • 3. Envoyer ce lien par WhatsApp ou email.
  • 4. Le client definit son mot de passe et ouvre son espace.
